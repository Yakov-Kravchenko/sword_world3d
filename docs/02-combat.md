# 02. Боевая система

Ядро игры. Модель — упрощённая и адаптированная D&D 5e. Все правила ниже описаны так, чтобы их можно было реализовать без «на усмотрение мастера»: каждое число либо задано, либо выводится формулой.

---

## 1. Базовые понятия

### 1.1 Сетка и пространство

- Бой идёт на **сетке с ячейкой 1.5 м** (соответствует 5 футам D&D). Геометрия подземелья генерируется кратно этой ячейке.
- Персонаж занимает 1 клетку. Крупные враги — 2×2, огромные (боссы) — 3×3.
- Диагональ считается как 1 клетку (правило Chebyshev-расстояния). Это упрощает ИИ и восприятие игроком.
- Клетка может быть: проходимая, непроходимая, труднопроходимая (2 очка движения), опасная (эффект при входе/начале хода), высокая (укрытие).

### 1.2 Характеристики

Шесть характеристик, диапазон 3–22. Модификатор:

```
модификатор = floor((значение - 10) / 2)
```

| Характеристика | Сокр. | На что влияет |
|---|---|---|
| Сила | СИЛ | Попадание и урон в ближнем бою тяжёлым оружием, толчок/захват, грузоподъёмность |
| Ловкость | ЛОВ | Попадание и урон лёгким/дальнобойным оружием, КБ в лёгкой броне, инициатива, уклонение |
| Телосложение | ТЕЛ | Максимальные хиты, спасброски против яда/болезни/кровотечения, концентрация |
| Интеллект | ИНТ | Сила заклинаний чернокнижника, знание монстров, поиск секретов, отмычки |
| Мудрость | МДР | Сила заклинаний знахарки, спасброски против страха/очарования, восприятие (ловушки, тайники) |
| Харизма | ХАР | Цены в лавке, варианты в диалогах, некоторые реликвии |

**Бонус мастерства (БМ)** — по уровню героя (см. [03-characters.md](03-characters.md)):

| Уровень героя | 1–3 | 4–6 | 7–9 |
|---|---|---|---|
| БМ | +2 | +3 | +4 |

### 1.3 Производные значения

```
Максимум хитов (HP)    = кость_класса_макс + ТЕЛ_мод + (уровень - 1) * (кость_класса_среднее + ТЕЛ_мод)
Класс брони (КБ)       = база_брони + min(ЛОВ_мод, лимит_брони) + щит + улучшение_брони + аффиксы
Инициатива             = d20 + ЛОВ_мод + бонусы
Скорость               = 6 клеток (9 м); тяжёлая броня при СИЛ < 13: 5 клеток
Пассивное восприятие   = 10 + МДР_мод + БМ (если владение)
Грузоподъёмность (кг)  = 15 + СИЛ * 1.5
```

**Кость класса** (для HP): латник d10, ловчая d8, знахарка d8, чернокнижник d6. Среднее округляется вверх (d10 → 6, d8 → 5, d6 → 4). HP не бросается случайно — фиксированное значение, чтобы прогресс был предсказуем.

## 2. Структура боя

### 2.1 Начало боя

1. Триггер: враг обнаружил отряд (проверка восприятия) ИЛИ игрок атаковал первым ИЛИ вход в комнату-арену.
2. Определяется **внезапность**:
   - Отряд заметил врага первым (скрытность отряда > пассивное восприятие врага) → враги **застигнуты врасплох**: пропускают первый ход.
   - Враг заметил отряд первым → **застигнут врасплох отряд**.
   - Иначе — обычный бой.
3. Бросок инициативы для каждого участника: `d20 + ЛОВ_мод`. При равенстве выше тот, у кого больше ЛОВ; при полном равенстве — случайно (детерминированный RNG боя).
4. Формируется **лента инициативы** — порядок ходов на весь бой (не перебрасывается).
5. Камера переключается в тактический режим, включается заполняющий свет, появляется боевой UI.

### 2.2 Ход персонажа

В свой ход персонаж имеет:

| Ресурс | Количество | Примеры |
|---|---|---|
| **Движение** | Скорость в клетках (обычно 6) | Можно дробить: 2 клетки → атака → 4 клетки |
| **Действие** | 1 | Атака, Заклинание, Рывок, Отход, Уклонение, Помощь, Толчок, Обыск, Взаимодействие с механизмом |
| **Бонусное действие** | 1 | Использовать зелье/повязку, вторая атака лёгким оружием, Спрятаться (ловчая), заклинания-бонусы |
| **Реакция** | 1 (обновляется в начале своего хода) | Атака при возможности, Парирование, Щит, Готовность |
| **Свободные** | Не ограничено разумно | Речь, бросить предмет из рук, взаимодействие с 1 объектом (открыть дверь, зажечь факел) |

Ход завершается по кнопке «Конец хода» или автоматически, если ресурсов не осталось и включена опция авто-передачи.

### 2.3 Раунд

Раунд = все участники сделали ход. Раунд ≈ **6 секунд игрового времени** (важно для длительности эффектов и таймера факела).

В начале раунда обрабатываются:
- Уменьшение таймеров эффектов зоны (ядовитое облако, огонь на полу).
- Проверка «горит ли факел» и обновление освещения.

### 2.4 Конец боя

Бой заканчивается, когда одна из сторон полностью выведена из строя или враги бегут (некоторые типы врагов бегут при HP < 25% и проваленной проверке МДР).

После боя:
- Эффекты с меткой `end_of_combat` снимаются (например, благословение цели).
- Лут выпадает на землю или сразу в инвентарь (настройка, по умолчанию — сразу, с уведомлением).
- Начисляется золото/руда/кристаллы по таблицам дропа.
- Хиты **не восстанавливаются** — только отдых или расходники.

## 3. Броски

### 3.1 Бросок атаки

```
d20 + БМ (если владение оружием) + модификатор_характеристики + улучшение_оружия_hit + аффиксы + ситуативные
результат >= КБ цели  →  попадание
```

- **Натуральная 20** → критическое попадание: все кости урона бросаются дважды (модификаторы не удваиваются). Попадание автоматическое.
- **Натуральная 1** → промах автоматически.
- Порог крита может снижаться до 19 или 18 аффиксами и навыками.

**Характеристика для атаки:**
- Тяжёлое ближнее (меч-полуторник, топор, молот, копьё) → СИЛ
- Лёгкое / фехтовальное ближнее (кинжал, рапира, короткий меч) → ЛОВ
- Дальнобойное (лук, арбалет, метательное) → ЛОВ
- Заклинания чернокнижника → ИНТ, знахарки → МДР

### 3.2 Преимущество и помеха

- **Преимущество:** бросить 2d20, взять больший.
- **Помеха:** бросить 2d20, взять меньший.
- Преимущество и помеха взаимно уничтожаются (одно любое преимущество гасит одну любую помеху; не складываются).

Источники (полный список — в коде через теги `ADV_SOURCE` / `DIS_SOURCE`):

| Преимущество | Помеха |
|---|---|
| Цель лежит (ближний бой) | Цель лежит (дальний бой) |
| Цель парализована/оглушена/скована | Атакующий ослеплён |
| Атакующий невидим/скрыт | **Атакующий в темноте (без источника света)** |
| Атака в спину (ловчая, навык) | Цель в темноте и не видна |
| Цель отравлена (для некоторых эффектов) | Атакующий отравлен |
| Помощь союзника (действие «Помощь») | Дальний бой в упор (враг в соседней клетке) |
| Цель окружена (2+ союзника вплотную) | Цель за укрытием (частичное: −2 КБ вместо помехи; полное: атака невозможна) |

### 3.3 Спасброски

```
d20 + модификатор_характеристики + БМ (если владение спасброском) >= СЛ  →  успех
```

**СЛ эффекта, наложенного персонажем:**
```
СЛ = 8 + БМ + модификатор_основной_характеристики + бонусы_снаряжения
```

**СЛ эффекта от врага/ловушки:** задаётся в данных врага/ловушки, растёт с глубиной (см. [07-economy.md](07-economy.md)).

Владение спасбросками по классам — в [03-characters.md](03-characters.md).

### 3.4 Проверки навыков

Используются вне боя (поиск секретов, отмычки, обезвреживание ловушек, скрытность, диалоги):
```
d20 + модификатор_характеристики + БМ (если владение) >= СЛ задачи
```

| СЛ | Сложность |
|---|---|
| 8 | Тривиально |
| 12 | Легко |
| 15 | Средне |
| 18 | Трудно |
| 22 | Очень трудно |

При проверке навыка отрядом (например, «заметить ловушку») берётся **лучший** член отряда автоматически, без запроса игроку.

## 4. Урон

### 4.1 Расчёт

```
базовый_урон   = кость_оружия + мод_характеристики + улучшение_damage + аффиксы
крит           = кости_оружия бросаются ×2 (модификаторы один раз)
модификатор_типа:
    уязвимость   → урон × 2
    сопротивление→ урон × 0.5 (округление вниз)
    иммунитет    → урон = 0
поглощение     = вычитается после модификатора типа (броня с «Поглощением N»)
итог           = max(1, round(...))    # попадание всегда наносит минимум 1
```

Порядок применения строго такой: **кости → плоские модификаторы → уязвимость/сопротивление → поглощение → минимум 1**.

### 4.2 Типы урона

**Физический:** рубящий, колющий, дробящий.
**Стихийный:** огонь, холод, молния, кислота, яд.
**Особый:** некротический, психический, священный.

Каждый враг в `EnemyData` имеет списки `resistances`, `vulnerabilities`, `immunities`. Это основной инструмент тактического разнообразия биомов: в ледяной крепости холод бесполезен, в болоте яд бесполезен, нежить иммунна к яду и уязвима к священному.

### 4.3 Хиты, ранения и смерть героя

- HP падает до 0 → герой **при смерти** (лежит, не действует).
- В начале каждого своего хода при смерти — **спасбросок от смерти**: d20, ≥10 успех, <10 провал. 3 успеха → стабилизация (0 HP, без сознания, но не умирает). 3 провала → **гибель**. Натуральная 20 → встаёт с 1 HP. Натуральная 1 → 2 провала.
- Любое лечение >0 HP поднимает героя с этим количеством HP, счётчик спасбросков сбрасывается.
- Урон по лежащему при смерти = 1 автоматический провал (крит = 2 провала).
- Действие «Стабилизировать» (проверка МДР СЛ 10 или бинт) останавливает спасброски.
- **Смерть героя окончательна в рамках забега.** Отряд продолжает спуск втроём. Если гибнут все четверо — конец забега.
- После забега погибшие герои возвращаются в строй вместе со своим снаряжением (нарративно — «их вытащили»). Внутри забега их смерть окончательна.

## 5. Действия: полный список

### 5.1 Основные действия (доступны всем)

| Действие | Эффект |
|---|---|
| **Атака** | Одна атака оружием (или несколько при навыке «Доп. атака») |
| **Заклинание** | Сотворение заклинания с временем «действие» |
| **Рывок** | Удвоить скорость на этот ход |
| **Отход** | Перемещение не провоцирует атаки при возможности |
| **Уклонение** | До начала след. хода: атаки по вам с помехой, ваши спасброски ЛОВ с преимуществом |
| **Помощь** | Союзник в соседней клетке получает преимущество на следующую атаку |
| **Толчок** | Состязание СИЛ: сдвинуть цель на 1 клетку или сбить с ног |
| **Готовность** | Задать триггер и действие; тратит реакцию при срабатывании |
| **Использовать предмет** | Крупные предметы, взаимодействие с механизмами |
| **Прицеливание** (ловчая) | +2 к следующей дальней атаке |

### 5.2 Бонусные действия (общие)

| Действие | Эффект |
|---|---|
| **Расходник** | Выпить зелье, наложить повязку, съесть еду, принять антидот |
| **Сменить факел** | Достать и зажечь новый факел |
| **Атака второй рукой** | Если в обеих руках лёгкое оружие: доп. атака без модификатора характеристики к урону |
| **Классовые** | См. [03-characters.md](03-characters.md) |

### 5.3 Реакции

| Реакция | Триггер |
|---|---|
| **Атака при возможности** | Враг покидает соседнюю с вами клетку, не используя Отход |
| **Парирование** (латник) | Вас атакуют: +3 к КБ против этой атаки |
| **Щит** (чернокнижник, заклинание) | Вас атакуют: +5 к КБ, может превратить попадание в промах |
| **Перехват** (латник) | Союзник рядом получает урон: принять половину на себя |
| **Готовое действие** | Сработал заданный триггер |

## 6. Заклинания и ячейки

### 6.1 Модель ячеек

Ячейки — по уровням от 1 до 5. Каждое заклинание имеет уровень; сотворение тратит ячейку **этого уровня или выше** (повышение уровня усиливает эффект у заклинаний с меткой `upcast`).

**Заговоры (уровень 0)** не тратят ячейки, доступны без ограничений, слабее — это «базовая атака» заклинателей.

Ячейки — до **3-го уровня** включительно (потолок мира в релизной версии).

| Ур. героя | 1-й | 2-й | 3-й |
|---|---|---|---|
| 1 | 2 | – | – |
| 2 | 3 | – | – |
| 3 | 4 | 2 | – |
| 4 | 4 | 3 | – |
| 5 | 4 | 3 | 2 |
| 6 | 4 | 3 | 3 |
| 7 | 4 | 3 | 3 |
| 8 | 4 | 4 | 3 |
| 9 | 4 | 4 | 3 |

⚠️ Таблица грузится из данных (`balance.tres`), а не задаётся массивом в коде: обновление с актом III добавит уровни 10–12 и ячейки 4–5 без правки логики.

**Восстановление:** только при отдыхе у алтаря между этажами (см. [04-dungeon.md § Отдых](04-dungeon.md#7-отдых-и-алтари)) и при возвращении домой. Зелье эссенции восстанавливает 1 ячейку уровня ≤3.

### 6.2 Концентрация

Некоторые заклинания требуют концентрации (метка `concentration`). Правила:
- Одновременно можно поддерживать только **одно** такое заклинание.
- При получении урона: спасбросок ТЕЛ, СЛ = max(10, полученный_урон / 2). Провал → заклинание рассеивается.
- Оглушение, паралич, потеря сознания, смерть → концентрация прерывается.

### 6.3 Компоненты и правила сотворения

- Дальность и форма области (сфера, конус, линия, куб) задаются в `SpellData` и отрисовываются превью на сетке до подтверждения.
- Заклинания требуют **линии видимости** к цели, если не указано иное. Стены и полное укрытие блокируют.
- Заклинания с меткой `ritual` можно творить вне боя без траты ячейки, занимая 10 минут (свет, обнаружение магии, очищение воды).

## 7. Статусные эффекты

Все обязательны (по требованию). Реализуются единой системой `StatusEffect` (Resource + runtime-инстанс), стакающаяся или нет по флагу.

| Статус | Механика | Длительность | Снятие |
|---|---|---|---|
| **Кровотечение** | В начале хода: 1d4 урона за стак, макс 5 стаков. Не даёт восстанавливать HP лечением ниже 100% эффективности (−50% лечения) | 3 раунда, обновляется при новом наложении | Повязка (бонусное действие), лечение ур. 2+, отдых |
| **Яд** | Помеха на броски атаки и проверки характеристик; 1d4 урона ядом в начале хода | 1 мин (10 раундов) | Антидот, «Очищение», отдых |
| **Отравление тяжёлое** | Как яд + −2 к КБ, спасбросок ТЕЛ в конце хода для снятия | До успеха | Антидот мгновенно |
| **Ожог** | 1d6 урона огнём в начале хода; −2 КБ (паника) | 2 раунда или до входа в воду | Вода, «Очищение», действие «Сбить пламя» (СЛ 10 ЛОВ) |
| **Обморожение** | Скорость −50%, реакция недоступна | 2 раунда | Огонь по цели снимает |
| **Заморозка** | Обездвижен, атаки по цели с преимуществом, урон огнём ×2 и снимает статус | 1 раунд, спасбросок ТЕЛ в конце | Урон огнём |
| **Оглушение** | Пропуск хода, автопровал спасбросков СИЛ/ЛОВ, атаки по цели с преимуществом | 1 раунд | — |
| **Паралич** | Как оглушение + ближние атаки по цели — автокрит | 2 раунда, спасбросок ТЕЛ в конце каждого хода | Антидот, «Очищение» |
| **Ослепление** | Помеха на свои атаки, преимущество атакующим, дальность зрения 0 | 2 раунда | «Очищение», отдых |
| **Страх** | Не может приближаться к источнику, помеха на атаки и проверки | 2 раунда, спасбросок МДР в конце хода | Аура храбрости латника, знахарка |
| **Замедление** | Скорость −50%, нет бонусного действия | 3 раунда | Рассеивание |
| **Проклятие** | −1d4 ко всем броскам d20; не снимается в подземелье | До конца забега или снятия в церкви/алтаре | Святая вода, алтарь очищения |
| **Болезнь** | Максимум HP −20%; накапливается до −60% | До конца забега | Редкое зелье, лекарь в деревне |
| **Обездвиженность** | Скорость 0, помеха на свои атаки, преимущество по вам | 2 раунда или до высвобождения (СИЛ СЛ 13) | Действие «Вырваться» |
| **Уязвимость (метка)** | Следующий урон определённого типа ×2 | 1 раунд | — |
| **Благословение** | +1d4 к атакам и спасброскам | Концентрация, 10 раундов | — |
| **Вдохновение** | +1d6 к одному броску на выбор | До использования | — |

**Правила стаканья:** статусы с флагом `stackable` накапливают стаки (кровотечение), остальные обновляют длительность до максимума из текущей и новой.

**Иммунитеты:** нежить иммунна к яду, отравлению, болезни, кровотечению; конструкты — ко всему списку ментального; элементали огня — к ожогу.

## 8. Освещение и темнота

Прямое следствие требования «факел горит по таймеру, темнота уменьшает точность в бою».

### 8.1 Три уровня освещённости клетки

| Уровень | Условие | Эффект |
|---|---|---|
| **Яркий свет** | В радиусе 6 клеток от факела/огня или в освещённой комнате | Нет штрафов |
| **Тусклый свет** | 6–12 клеток от источника | Помеха на проверки Восприятия; дальнобойные атаки на дистанции >6 клеток с помехой |
| **Темнота** | Нет источника | **Помеха на все броски атаки**; цель считается невидимой (атака вслепую); герой не видит врагов дальше 2 клеток |

Существа с **тёмным зрением** (большинство обитателей подземелья, ловчая с навыком) видят в темноте как в тусклом свете на 12 клеток — то есть темнота даёт им преимущество над отрядом.

### 8.2 Факел

- Расходник. Один факел горит **600 секунд времени исследования** ИЛИ **100 раундов боя** (счётчик единый, в «тиках»: 1 сек исследования = 1 тик, 1 раунд боя = 6 тиков).
- Держит один герой в слоте «свободная рука» (нельзя со щитом или двуручным оружием — тактический выбор).
- За 60 тиков до конца — предупреждение (мигание, звук, красная иконка).
- Погас → у отряда 1 ход, чтобы зажечь новый (бонусное действие). Иначе темнота.
- Альтернативные источники: фонарь (перезаряжаемый маслом, дороже, ярче), заклинание «Свет» (ритуал, 1 час, но виден врагам издалека → +25% шанс случайной встречи), светящийся гриб (слабый, 3 клетки).

### 8.3 Реализация в Godot

- Освещённость клетки вычисляется **логически**, не по рендеру: `LightService.get_light_level(cell) -> BRIGHT | DIM | DARK`, на основе списка активных источников (позиция + радиусы) и проверки прямой видимости через `RayCast3D` по сетке. Результат кэшируется на раунд.
- Визуально: `OmniLight3D` с тенями только у факела (1 источник теней в кадре), остальные источники — без теней. Плотный `FogVolume` / environment fog.

## 9. Укрытия и высота

| Укрытие | Условие | Эффект |
|---|---|---|
| Нет | Прямая линия | — |
| Половинное | Низкое препятствие между (ящик, парапет) | +2 КБ, +2 спасброски ЛОВ |
| Три четверти | Колонна, угол стены | +5 КБ, +5 спасброски ЛОВ |
| Полное | Нет линии видимости | Нельзя атаковать напрямую |

**Высота:** атака сверху вниз (разница ≥1.5 м) даёт +1 к броску атаки. Полноценной системы вертикальности с прыжками нет — только площадки-возвышения в комнатах-аренах.

## 10. Враги и ИИ

### 10.1 Статблок врага (`EnemyData`)

```
id, отображаемое_имя, биомы[], тир_глубины
HP, КБ, скорость, размер
характеристики[6], БМ
владения_спасбросками[]
атаки[]: {имя, тип, бонус_атаки, кости_урона, тип_урона, дальность, эффект_при_попадании}
способности[]: {условие_использования, эффект, кулдаун}
сопротивления[], уязвимости[], иммунитеты[]
тёмное_зрение: bool
поведение: AGGRESSIVE | RANGED | SUPPORT | AMBUSH | SWARM | GUARD
мораль: порог_бегства (0.0 = не бежит)
таблица_дропа
очки_опасности (для бюджета встреч)
```

### 10.2 ИИ: архитектура

**Utility AI** (оценка полезности), не дерево поведения — проще расширять и отлаживать, естественно даёт разнообразие.

Каждый ход враг:
1. Собирает список **возможных действий**: (способность × цель × позиция).
2. Оценивает каждое по формуле полезности:
   ```
   score = ожидаемый_урон * w_dmg
         + шанс_убить * w_kill
         + ценность_эффекта * w_effect
         + безопасность_позиции * w_safety
         - риск_атак_при_возможности * w_risk
         + бонус_архетипа
   ```
3. Выбирает лучший вариант; при близких оценках (в пределах 10%) — случайный из них (чтобы не был предсказуем и детерминированно-скучен).
4. Веса `w_*` задаются архетипом в `EnemyData`.

**Архетипы:**
- `AGGRESSIVE` — максимизирует урон, идёт в ближний бой, игнорирует риск.
- `RANGED` — держит дистанцию 4+ клетки, отходит при сближении, ищет линию видимости.
- `SUPPORT` — лечит/усиливает союзников, прячется за ними, атакует только если некого поддержать.
- `AMBUSH` — прячется в темноте, атакует со скрытности (преимущество), отступает и снова прячется.
- `SWARM` — идёт толпой, стремится окружить (бонус за атаку в окружении).
- `GUARD` — не покидает зону охраны (сокровищница, алтарь), агрится только на вошедших.

**Целеприоритет по умолчанию:** ближайшая цель с наименьшим HP, с модификаторами: +30% приоритета к целям без брони (чернокнижник, знахарка), −20% к целям под «Провокацией» латника (то есть провокация принудительно повышает приоритет латника на +200%).

⚠️ **Ограничение производительности:** оценка вариантов ограничена — максимум 40 позиций × 6 способностей × 8 целей на врага, с ранним отсечением. Тяжёлые расчёты вынести в `WorkerThreadPool`, если ход врага занимает >100 мс.

### 10.3 Бюджет встреч

Каждый враг имеет `очки_опасности` (ОО). Генератор комнаты получает бюджет:

```
бюджет(глубина D, тип комнаты T) = базовый_бюджет(D) * множитель(T)
базовый_бюджет(D) = 10 + 6 * D
множители: обычная 1.0, элитная 1.6, логово стража 2.2, босс — отдельный сценарий
```

Состав встречи собирается жадным алгоритмом из пула биома с правилами: не более 8 врагов на комнату, минимум 1 «якорь» (сильный враг) при бюджете >60, не более 2 `SUPPORT` на встречу.

## 11. Скорость игры и удобство

⚠️ Пошаговый бой на 4 героев × 20 этажей утомляет, если каждый ход длится долго. Обязательные меры:

- **Ускорение анимаций врагов** — глобальный множитель скорости 1.0/1.5/2.0/3.0 в настройках, по умолчанию 1.5.
- Все анимации боя прерываемы: пробел = «доиграть мгновенно».
- Ходы нескольких врагов одного типа, не влияющих друг на друга, могут проигрываться **параллельно** (флаг `allow_parallel_turn`).
- Логика хода врага рассчитывается заранее, пока играет анимация предыдущего.
- Целевое время полного раунда (4 героя + 5 врагов) при множителе 1.5: **≤ 45 секунд**.
- Показ бросков (d20 катится) — короткая, но выразительная анимация 0.5 с; отключаемая.
- Автоматический пропуск хода героя без доступных действий.

## 12. Смерть, поражение и последствия

### 12.1 Конец забега

Забег заканчивается тремя способами:

| Исход | Условие | Результат |
|---|---|---|
| **Успешный выход** | Игрок ушёл через Врата Возврата 1 (эт. 10) | Вся добыча сохраняется |
| **Гибель отряда** | Все четыре героя мертвы | Добыча забега теряется |
| **Прохождение** | Побеждена Матерь Топей на 20-м этаже | Добыча сохраняется + концовка |

### 12.2 Что теряется при гибели отряда

Решено (v1.1): режим один, `DEATH_RULES.preset = "roguelite"`. Хардкорный `classic` из ТЗ вычеркнут.

| Сохраняется **всегда** | Теряется при гибели отряда |
|---|---|
| **Всё снаряжение героев** — надетое и в сумках, включая улучшения, кристаллы и аффиксы | Золото, руда, кристаллы, добытые в этом забеге и не вынесенные через Врата |
| Всё содержимое склада и дома | Все расходники, взятые в забег и найденные в нём |
| Купленные узлы дерева навыков, уровень отряда | Все благословения забега |
| Уровни зданий, декор, сад | Прогресс по этажам (следующий забег — с 1-го) |
| Разблокировки биомов, рецептов, записей лора, трофеи | Предметы снаряжения, **найденные в забеге** и не вынесенные |

Ключевое различие: **снаряжение, которое ты взял с собой из дома, возвращается всегда** (нарративно — тела вытаскивают вместе с их вещами). Теряется только то, что ты добыл внизу и не успел вынести. Именно это делает Врата Возврата настоящим решением, а не формальностью.

Погибшие герои возвращаются в строй к следующему забегу (без штрафов, кроме нарративных реплик).

### 12.3 Экран итогов забега

Показывает: глубина, время, убито врагов, побеждено боссов, собрано ресурсов (и сколько из них потеряно), лучший урон одним ударом, причина смерти, обновления рекордов. Кнопка «В деревню».
