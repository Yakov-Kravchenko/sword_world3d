# 09. Интерфейс, арт и звук

## 1. Управление

### 1.1 Подземелье — исследование (3-е лицо за спиной лидера)

| Клавиша | Действие |
|---|---|
| W/A/S/D | Движение лидера, остальные трое идут следом «змейкой» |
| Мышь | Поворот камеры |
| Колесо | Дистанция камеры (3 фикс. положения) |
| Shift | Быстрый шаг (не влияет на бой, тратит тики факела быстрее) |
| E | Взаимодействие |
| Tab | Карта этажа |
| I | Инвентарь отряда |
| C | Лист персонажей |
| J | Журнал/лор |
| F | Зажечь/сменить факел |
| 1–4 | Выбрать активного героя (для взаимодействий и проверок) |
| Esc | Меню |

### 1.2 Подземелье — бой

| Клавиша | Действие |
|---|---|
| ЛКМ по клетке | Переместиться / подтвердить цель |
| ПКМ | Отмена / выход из режима нацеливания |
| 1–9 | Способности активного героя с панели действий |
| Q/E | Поворот тактической камеры на 45° |
| Колесо | Приближение |
| Пробел | Пропустить/ускорить анимацию |
| Enter | Конец хода |
| Alt (удерживать) | Показать все интерактивные объекты и подписи |
| Tab | Переключить активного героя (если ещё не ходил) |
| Z | Отменить последнее движение (если ещё не было других действий) — **обязательно**, иначе мискликами игрок теряет ходы |

### 1.3 Деревня и дом (1-е лицо)

| Клавиша | Действие |
|---|---|
| W/A/S/D + мышь | Ходьба и обзор |
| E | Взаимодействие (станки, NPC, двери) |
| T | Режим декорирования (только в своём доме) |
| R | Поворот предмета в режиме декора |
| Shift | Отключить привязку к сетке |
| Ctrl+Z / Ctrl+Y | Отмена/повтор в декоре |

**Геймпад:** полная поддержка обязательна для Steam Deck-верификации. Все меню навигируемы стиком, есть радиальное меню способностей.

## 3. Правила боевого интерфейса (референс DD2)

Главная задача — **игрок должен понимать, что произойдёт, до подтверждения действия**.

### 3.1 Обязательные элементы

- **Шанс попадания в процентах** на цели при наведении: `72%`, и при раскрытии (Alt) — полная формула: `d20 + 3(БМ) + 4(СИЛ) + 2(оружие) = 9 против КБ 16`.
- **Предпросмотр урона:** `12–19 (сред. 15)`, с учётом сопротивлений цели (`×0.5 сопр. огню` подсвечивается).
- **Подсветка сетки:** синий — доступное движение, оранжевый — с рывком, красный — зона поражения врага, жёлтый — область эффекта заклинания.
- **Зоны провокации:** при наведении на клетку показываются иконки атак при возможности, которые спровоцирует перемещение.
- **Иконки статусов** на портретах и над моделями: 32×32, с числом стаков и оставшихся раундов, тултип с полным описанием.
- **Лента инициативы:** портреты в порядке хода, текущий увеличен, при наведении на портрет — подсветка соответствующей модели на арене.
- **Лог боя:** каждая строка с раскрытием бросков, цветовое кодирование, прокрутка, копирование текста (для багрепортов).

### 3.2 Стиль иконок

- Формат 128×128 PNG, вектор-источник.
- Толстый тёмный контур (3–4 px в масштабе 128), силуэт читается на 32×32.
- Ограниченная палитра: 4–6 цветов на иконку, фон — приглушённый цвет школы/типа.
- Цветовое кодирование: физический — сталь-серый, огонь — оранжевый, холод — голубой, яд — зелёный, некротический — фиолетовый, священный — золотой, лечение — светло-зелёный, бафф — синий, дебафф — тёмно-красный.
- **Объём:** ~140 иконок (38 заклинаний + 45 способностей + 17 статусов + 25 предметов-категорий + UI).

### 3.3 Шрифты и читаемость

- Основной шрифт — гротеск с хорошей кириллицей (например, `Involve`, `Rubik`, `PT Sans`), лицензия SIL/OFL.
- Заголовочный — с характером, но читаемый; не готика.
- Минимальный кегль 16 px при 1080p. Настройка масштаба UI 80–150%.
- Контраст текста к фону ≥ 4.5:1 (WCAG AA).

## 4. Доступность

Обязательный минимум (и требование части аудитории Steam):

- Масштаб UI и размер шрифта.
- Режим для дальтоников: альтернативные цвета подсветки + всегда дублирующие иконки/формы, а не только цвет.
- Отключение тряски камеры и вспышек, снижение частоты миганий.
- Полное переназначение клавиш.
- Скорость анимаций (уже есть по геймплейным причинам).
- Опция «Показывать все броски текстом» для тех, кому неудобны анимации кубиков.
- Субтитры для всех звуковых событий сюжетных сцен.

## 5. Арт-пайплайн

### 5.1 Бюджеты полигонов и текстур

| Объект | Треугольники | Текстура | Кости |
|---|---|---|---|
| Герой | 4 000–6 000 | 512 albedo (атлас на всех 4) | ≤ 45 |
| Враг обычный | 1 200–3 000 | 512 (общий атлас биома) | ≤ 45 |
| Босс | 6 000–10 000 | 1024 | ≤ 60 |
| Модуль комнаты | 800–3 000 | из атласа биома 2048 | — |
| Проп крупный (сундук, статуя) | 300–900 | из атласа | — |
| Проп мелкий (кость, кружка) | 40–200 | из атласа | — |
| Оружие | 300–800 | 256 | — |
| Мебель/декор | 200–800 | из атласа декора | — |

### 5.2 Общий риг — ключевое решение

**Один гуманоидный скелет** (Mixamo-совместимый) для 4 героев и всех гуманоидных врагов (гоблины, скелеты, культисты, солдаты, ведьмы — ~60% бестиария).

**Библиотека анимаций (единая, ~45 клипов):**
idle, idle_боевой, ходьба, бег, поворот, атака_меч ×3, атака_топор, атака_копьё, атака_двуручник, выстрел_лук, выстрел_арбалет, каст_быстрый, каст_долгий, блок, парирование, уклонение, получение_урона ×2, смерть ×2, при_смерти, вставание, использование_предмета, взаимодействие, открывание, победа, страх, оглушение, лежит.

Неgumanоидные скелеты: **паук/многоногое**, **четвероногое**, **летающее**, **аморфное** (слизь/споры) — по 12–18 анимаций каждый. Всего 5 ригов.

⚠️ Это решение экономит примерно 60–70% времени на анимации. Без него проект вдвоём нереализуем.

### 5.3 Источники ассетов

Разрешено и рекомендовано (при «минимальных вложениях»):
- Kenney.nl (CC0) — прототипирование, пропсы, иконки-заглушки
- Quaternius, Kay Lousberg (CC0) — low-poly модели, хорошо совпадают со стилем
- Mixamo (бесплатно) — базовые анимации, дорабатываются в Blender
- Poly Haven (CC0) — текстуры, HDRI
- Freesound (CC0/CC-BY), Kenney Audio — SFX-основа
- **Правило:** любой сторонний ассет проходит унификацию (перекраска в палитру биома, упрощение) — иначе будет «сборная солянка», главный визуальный признак дешёвой игры.

### 5.4 Порядок производства

1. Блокинг всей игры на серых кубах (Фаза 0–1) — играбельно до единой модели.
2. Один эталонный биом целиком (Катакомбы) — устанавливает планку качества.
3. Остальные биомы по шаблону эталона.
4. Персонажи: сначала один герой полностью (модель → риг → анимации → интеграция), затем остальные.
5. UI: сначала функциональные заглушки, финальная графика — Фаза 4.

## 6. Звук

### 6.1 Объём

| Категория | Кол-во | Примечание |
|---|---|---|
| Музыка | 9 треков | Меню, деревня, 6 биомов (по 1 эмбиентному треку; «глубокие» версии используют тот же трек с изменённым миксом), боевая тема, боссы ×2, финал |
| Эмбиент | 8 петель | По биому: капли, ветер, гул, скрип |
| SFX бой | ~60 | Удары по типам оружия × материалам цели, промахи, криты, заклинания по школам, смерти |
| SFX интерфейс | ~20 | Клики, инвентарь, покупка, улучшение (успех/провал — важные, эмоциональные) |
| SFX мир | ~35 | Шаги по 5 поверхностям, двери, сундуки, ловушки, факел, огонь |
| Вокализации | ~28 | По 7 на героя: усилие, боль, смерть, победа |
| **Итого** | **~150** | |

### 6.2 Технические правила

- Шины: `Master → Music / SFX / Ambient / UI / Voice`. Отдельные ползунки в настройках.
- Формат: музыка `.ogg` (стрим), SFX `.wav` 16-bit 44.1 kHz (в память).
- Пул из 24 `AudioStreamPlayer3D` с переиспользованием — не создавать плееры на лету.
- Случайная вариация питча ±8% и выбор из 2–4 вариантов на каждый частый звук (шаги, удары) — убирает «пулемётность».
- Кроссфейд музыки 1.5 с при входе в бой и выходе.
- Приглушение эмбиента на −6 дБ во время диалогов.
- Звук улучшения предмета в кузнице: **два разных, отчётливых** для успеха и провала — это эмоциональный пик мета-игры.

### 6.3 Музыкальное направление

Тёмный минимализм: низкие струнные, ударные с реверберацией, вокальные гулы без слов, редкие акценты. В деревне — единственное место с теплом: акустическая гитара/лютня, спокойный темп. Контраст обязателен.

## 7. Локализация

- Все строки — в `.csv` → `.translation` через встроенную систему Godot.
- Ключи вида `ITEM_SWORD_IRON_NAME`, `SPELL_FIREBOLT_DESC`. Ни одной строки прямо в коде или сцене.
- Языки релиза: **русский** (оригинал), **английский**.
- Учесть: английский текст в среднем на 15–20% короче русского — верстать UI по русскому, проверять по обоим.
- Числа и падежи: использовать форматирование с явными формами множественного числа (`3 зелья / 5 зелий`) через отдельные ключи.
