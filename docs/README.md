# Sword World 3D — Техническое задание

**Версия документа:** 1.2 (06.09.2026)
**Статус:** объём релиза утверждён (Вариант Б), готово к старту Фазы 0
**Команда:** 2 человека, полная занятость
**Движок:** Godot 4.4+ (Forward+), GDScript со статической типизацией
**Платформа:** Windows (Steam), позже Linux/Proton
**Целевое железо (минимум):** Intel Core i5 4-го поколения, 8 ГБ RAM, NVIDIA GTX 1660 / 1080p / 60 FPS

---

## Что это за игра (одно предложение)

Пошаговый рогалик по правилам, близким к D&D 5e: отряд из четырёх героев спускается на 20 этажей процедурно генерируемого подземелья, а между забегами игрок от первого лица живёт в собственном доме — кузница, тренировочный зал, лавка, сад и склад превращают добытые ресурсы в постоянную силу.

## Ключевые решения (сводка)

| Аспект | Решение |
|---|---|
| Камера | 3-е лицо за спиной лидера в подземелье; тактическая камера в бою; **1-е лицо** в доме и деревне |
| Бой | Пошаговый на сетке 1.5 м, инициатива d20, действие + бонусное действие + реакция + движение |
| Магия | Ячейки заклинаний по уровням (D&D-модель), восстановление только на отдыхе |
| Отряд | 4 фиксированных героя; игрок выбирает «основного» — его дом становится хабом, за него играешь от 1-го лица |
| Забег | **20 этажей = 2 акта по 10**; внутри акта 3 биом-сегмента по 3 этажа + этаж-логово босса |
| Биомы | **6 базовых** (акт I) + **их «глубокие» версии** (акт II) — те же модули комнат, другая палитра, пул врагов и механика |
| Боссы | **2 уникальных босса акта** (этажи 10 и 20) + Вестник на этажах 5 и 15 + Страж этажа (элита) на каждом этаже |
| Уровни | Отряд 1–9, БМ до +4, ячейки заклинаний до 3-го уровня, 38 заклинаний |
| Благословения | Временный бонус на выбор на этажах 5, 10, 15, 20 (4 раза за забег) |
| Выход с лутом | **Врата Возврата после каждого босса акта** (этажи 10 и 20): уйти с добычей или идти дальше. Между вратами выхода нет |
| Смерть | Гибель отряда = конец забега, вся несохранённая добыча теряется. **Снаряжение и мета-прогресс сохраняются всегда** |
| Свет | Факел с таймером, сменные расходники; тьма = помеха на атаку |
| Валюты | Золото (расходники, навыки, декор), Руда 3 тиров (улучшение **+1…+8**), Кристаллы 6 типов (вставка, случайные префиксы) |
| Инвентарь | Сетка + предел веса, лимит 5 зелий и 5 антидотов на героя |
| Стиль | Стилизованный low-poly с ручной покраской, тёмная палитра, плотный туман, свет от факела |
| Мультиплеер | Нет. Только одиночная игра |
| Сроки | **16 месяцев по плану**, реалистично 18–22 |

## Объём релиза и развитие

Это ТЗ описывает **релизную версию**. Полный задуманный объём (акт III с финальным боссом, 10 биомов, уровни 10–12, улучшение до +10, заклинания 4–5 уровня) достигается **тремя пострелизными обновлениями** — план, содержание и сроки в [11-scope-variants.md §5](11-scope-variants.md#5-путь-б--а-обновления-после-релиза).

⚠️ **Ключевое техническое требование, действующее с первого дня:** число актов, потолки уровня и улучшения, список биомов, таблица ячеек и ряды дерева навыков живут **только в данных**. Ни одно из этих значений не должно появиться в коде как литерал или `enum` — иначе путь к полной версии закроется. Чек-лист: [08-architecture.md §4.1](08-architecture.md#41-расширяемость-содержание-релиза-задаётся-данными).

## Требуют твоего решения (до старта Фазы 1)

1. **Список биомов.** Шесть базовых утверждены предварительно: Катакомбы, Шахты, Грибные пещеры, Болото, Некрополь, Ледяная крепость. Огненная крепость перенесена в обновление. Сверить в [04-dungeon.md § Биомы](04-dungeon.md#4-биомы).
2. **Визуальный стиль.** Рекомендация обоснована в [01-concept.md § Визуальный стиль](01-concept.md#4-визуальный-стиль).

## Как читать это ТЗ

- Разделы **«Формулы»** и **«Константы»** — это то, что идёт в код без изменений (файл `res://data/balance/balance.tres`).
- Разделы **«Приёмка»** в конце каждого документа — критерий «сделано», по нему проверяем задачу.
- Всё, что помечено 🔶 — предложение, требующее решения.
- Всё, что помечено ⚠️ — риск для двух человек с нулевым опытом; читать внимательно.
